# 待机与电流测量

Metalio Claw 4 使用两阶段待机：短暂黑屏保留无线连接，连续黑屏达到 10 分钟后关闭无线外围并启用自动轻睡眠。

## 待机行为

| 连续黑屏时间 | CPU 目标频率 | Wi-Fi / 蓝牙模块 | P4 自动轻睡眠 |
| --- | --- | --- | --- |
| 前 10 分钟 | 40 MHz | 保持供电及现有连接 | 未启用 |
| 满 10 分钟后 | 40 MHz | Wi-Fi 停止，C5 保持复位，蓝牙断电 | 启用 |

黑屏时关闭背光与显示传输，并暂停应用音频采集、唤醒词、音频 DMA 和运动传感器。路由器主动断开等外部原因仍可能触发网络重连。

唤醒后重新开始待机计时。重复待机请求不会延长正在进行的黑屏计时，外围停机失败时按间隔重试。长待机唤醒先恢复音频，再恢复网络；网络连接优先使用上次成功热点的信道和 BSSID，失败后回退完整扫描。

## 使用待机测试页

1. 在设备应用列表打开 **待机测试**。
2. 选择 **手动待机**立即黑屏。
3. 短按侧键亮屏，再向右滑动解锁。

**15秒自动唤醒**和**60秒自动唤醒**用于观察短待机电流与唤醒过程。它们在前 10 分钟内保留联网，结果不代表长待机电流。观察长待机应保持黑屏至少 11 分钟。

测电池耗电时断开 USB、充电器和无线充电底座。电量计的负电流表示放电；短时间采样用于观察当前状态，续航需要较长时间的电池放电测量。

## 构建与设备操作

在仓库根目录运行 `npm run package` 构建并打包固件，产物位于 `build/esp32/`。

更新应用并保留设备设置时，先检查目标端口与镜像：

```sh
npm run flash:preserve -- -Port COM10 -DryRun
```

确认后去掉 `-DryRun` 写入设备。`COM10` 应替换为设备实际枚举的串口号。串口监控使用 `npm run monitor -- -Port COM10`。

完整参数和 ESP-IDF 配置见 [开发与烧录](development.md)。
