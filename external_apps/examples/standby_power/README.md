# 待机功耗 1.0.0

将 `standby-power-1.0.0.eapp` 放到 SD 卡的 `/metalio/apps/`，重启设备后，从主页打开“待机功耗”。需要支持 `METALIO_APP_CAP_POWER_DIAGNOSTICS` 的配套固件。

- 显示当前 CPU 频率、应用频率上限、黑屏目标频率、电量、电池电压与电流。
- “手动待机”立即黑屏，由侧键唤醒。
- “15 秒唤醒”和“60 秒唤醒”在确认屏幕停止后采样，随后自动恢复待机锁屏。解锁后查看测量结果。
- 结果包含黑屏频率、有效电流采样数、平均电流以及成功轻睡眠时长与次数。侧键提前唤醒会取消本次定时测试。
- 退出应用会取消它的定时测试；再次打开后可重新发起。

这两个定时窗口保留正常的 Wi-Fi/蓝牙宽限期，测得的电流对应联网黑屏阶段。连接外部电源时电流仅供参考；它们不能代表十分钟后的断网长待机电流或整机续航。

界面与交互在外部应用中实现，通过 ABI 1 尾部的功耗接口读取数据和请求待机。黑屏采样与自动唤醒由宿主执行，以便屏幕停止刷新后仍可继续测量。

构建：在 ESP-IDF 环境中运行 `external_apps/build-standby-power.ps1`。
