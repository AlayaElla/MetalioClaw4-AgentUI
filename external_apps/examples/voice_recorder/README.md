# 录音机 1.0.0

将 `voice-recorder-1.0.0.eapp` 放到 SD 卡的 `/metalio/apps/`，重启设备后，主页会出现“录音机”。

- 点击计时下方的“录音”，观察麦克风电平、波形、计时和音频大小。
- 点击“保存”，录音保存到 `/Recordings/Voice.wav`；已有文件会自动编号，保留原录音。
- 点击“回放”播放刚才保存的录音，点击“停止”结束回放。
- 点击“取消”删除正在录制的这一次录音。以前保存的录音保留。
- 单次最长 5 分钟。退出应用会停止并保存当前录音。

超过 1.5 秒仍没有音频时，界面显示“尚未收到麦克风音频”。空录音不会成为可回放的新录音。
录音使用设备的麦克风和处理后 PCM，不经过 PC 或虚拟声卡。

应用使用 `design/agent` 的字号、主题与按钮样式。录音、回放和取消位于计时下方、波形上方，底部为系统返回按钮。
需要配套固件提供本地 WAV 回放支持。应用和固件编译通过后，仍需在设备上验证麦克风与回放。
配套固件包含退出 Codex 听写页面时的占用清理修复，并会记录无法开始录音的具体原因。
等待 Wi-Fi 配置或小智激活时也可以本地录音；实际通话、听写或音频测试期间仍会提示占用。

构建：在 ESP-IDF 环境中运行 `external_apps/build-voice-recorder.ps1`。
